# Product

Inbind CMS is a live, actively acquired content management workspace available at cms.inbind.app. It connects to Webflow via direct API and to Webstudio, Astro, Next.js, Nuxt, and SvelteKit via JSON files on user-owned S3/R2 storage. The current focus is on deepening generated fields with ready-made templates. The longer-term vision is an opinionated AI-powered content operations platform — from brief to published piece — that handles the "How" so content teams can own the "What".
